FVで袋が流れる動き（PCの縦2列・スマホの横2列）は、CSSアニメーションではなくJSの `flowStrip()` で毎フレーム位置を指定しています（CSSアニメーションだと、iPhoneのSafariで画面外だった部分が描かれず袋の列が消えたり、更新すると止まったりするため）。速さは `flowStrip(…,秒数)` の秒数（半周にかける時間。スマホ50秒・PC70秒）で変更できます。

`prefers-reduced-motion`（OSで「視差効果を減らす」を設定している方）には動きを止めて表示します。

## 大きな画面での表示
デスクトップ（1920px など）でも大きくなりすぎないよう、文字や数字は画面幅に合わせて大きくなる上限を決めています。メインの幅は1040px（`:root` の `--cw`）、最初の画面は高さ最大820px。
